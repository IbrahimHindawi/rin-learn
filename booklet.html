Chapter 1

The Core Idea

C is not C because of punctuation. C is C because it keeps the physical program visible: memory, addresses, contiguous arrays, structs as layout, enums as named integers, and procedures as callable symbols.

I keeps that model. It does not try to hide the machine. It tries to make the shape of the program easier to write, easier to check, and easier for tools to understand.

Memory

Values live in storage. Pointers name storage. Arrays put values next to each other.

Layout

A struct is a promise about fields and offsets. That promise matters when talking to C.

Compilation

I lowers to C. The generated C is useful evidence, not a secret.

Point: struct = {
    x: f32;
    y: f32;
}

Chapter 2

How To Read A Lesson

Each lesson is a full program. Read the comments, compile it, and then look at the generated C when the lowering is interesting.

The rule of thumb is small and reliable:

read the I
compile the I
inspect the C
change one thing
compile again

That loop teaches more than a big reference page. It makes every feature answer a practical question.

The lesson files are intentionally short. When a file grows too much, it stops being a lesson and becomes a project.

Chapter 4

Where I Starts To Be I

The first lessons are mostly C ideas in I syntax. The later lessons show why the syntax is worth having.

Generics let one source definition become concrete code:

Box: struct<T> = {
    value: T;
}

Box<T>make: proc<T>(value: T)->Box<T> = {
    box: Box<T> = {};
    box.value = value;
    return box;
}

Reflection gives generated metadata for the data you already wrote:

printf("%s %llu\n", Payload<>.name, Payload<>.field_count);

The spirit is concrete metaprogramming: less handwritten boilerplate, more checkable generated shape.

Chapter 5

The Check Ritual

Use the check script whenever you change a lesson:

powershell -ExecutionPolicy Bypass -File scripts/check_all.ps1

It finds I.exe through I_HOME, then PATH, then C:\devel\i-windows-x64\I.exe. It compiles every lesson into build/gen.

If all is well, it ends with:

ok 14 lessons
A learning repo should keep this ritual boring. The interesting part is the source, not the build ceremony.
